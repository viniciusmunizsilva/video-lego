# Opening assets — first delivery

This directory contains the first visual assets for the 30-second vertical LEGO CENA EM CENA promo.

## Files
- `projector/projector.png`: isolated vintage film projector; 1086 × 1448; RGBA with alpha channel (alpha range 0–255).
- `clapperboard/clapperboard.png`: isolated black-and-white clapperboard; 1312 × 1199; RGBA with alpha channel (alpha range 0–255).
- `studio-background/studio-background-vertical.png`: vertical studio background plate; 941 × 1672; RGB (no alpha), contains integrated studio equipment and elements.
- `studio-background/studio-background-vertical-alt.png`: alternate vertical studio plate; 941 × 1672; RGB (no alpha), contains integrated studio equipment and elements.

## Important production notes
- The projector and clapperboard files have real alpha channels. Inspect edge quality at working scale before final compositing.
- The clapperboard image includes a LEGO wordmark on its center plate; treat as a visual prop/reference and replace with approved artwork if needed.
- Background plates are not transparent and are not clean 3D scene layers. They are vertical composite backgrounds intended for 2.5D camera movement/cropping.
- The generated images are 941 × 1672 for background plates rather than exact 1080 × 1920; upscale/crop carefully during scene assembly.
- Original generation files were retained in the conversation's working files; these repository copies use descriptive filenames.
